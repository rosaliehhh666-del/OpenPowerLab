## 测试环境要求

### 仪器设备

| 设备 | 规格要求 | 用途 |
| --- | --- | --- |
| 直流稳压电源 | 0-30V / 0-5A，带限流 | 供电测试 |
| 数字万用表 | 四位半及以上精度 | 电压电流测量 |
| 示波器 | ≥ 100 MHz 带宽 | 纹波、瞬态测试 |
| 电子负载 | 0-30V / 0-10A | 负载测试 |
| 红外测温仪 | -20~300℃ | 温度测试 |
| 高精度电流表 | 0-5A，0.1% 精度 | 电流校准 |

### 测试条件

- 环境温度：25 ℃ ± 5 ℃
- 输入电压：9 V / 12 V / 15 V / 20 V
- 散热条件：自然对流，无风冷

## 验证标准

### 电源板合格标准（建议）

- [ ] 输入 9-20V 范围内各路输出正常
- [ ] +5V / +3.3V 输出精度优于 ±5%
- [ ] 负载调整率优于 ±5%
- [ ] 输出纹波 < 50 mVpp（满载）
- [ ] 反接不损坏
- [ ] 连续满载 30 分钟不过热

### 监测板合格标准（建议）

- [ ] 电压测量精度优于 ±1%（校准后）
- [ ] 电流测量精度优于 ±2%（校准后）
- [ ] OLED 显示正常
- [ ] 串口输出稳定
